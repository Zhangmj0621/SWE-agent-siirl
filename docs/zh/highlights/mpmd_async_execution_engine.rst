MPMD 异步执行引擎
=================

   **适合谁：** 需要理解 siirl-agentic 异步训练架构的用户。

   **你将获得：** 理解 MPMD（多程序多数据）架构如何实现训练和 rollout 的完全解耦。

核心设计
--------

siirl-agentic 采用 MPMD 架构，三个核心组件作为独立 Ray Actor 运行：

::

   ┌─────────────────────────────────────────────┐
   │              MainRunner (编排)               │
   │                                             │
   │  ┌─────────┐  ┌──────────────┐  ┌────────┐ │
   │  │ Trainer  │  │RolloutManager│  │DataBuf │ │
   │  │(GPU 训练)│  │ (推理+环境)  │  │ (缓冲) │ │
   │  └────┬─────┘  └──────┬───────┘  └───┬────┘ │
   │       │               │              │      │
   │       └───────────────┼──────────────┘      │
   │                       │                      │
   │              TaskCoordinator                 │
   │              (生命周期管理)                   │
   └─────────────────────────────────────────────┘

异步流水线
~~~~~~~~~~

1. RolloutManager 持续执行多轮 rollout（生成 → 工具调用 → 环境反馈）
2. 完成的样本被推入 DataBuffer
3. Trainer 从 DataBuffer 异步消费样本
4. 训练更新后，参数同步回 Rollout 引擎

关键优势
~~~~~~~~

+-----------------------------------+-----------------------------------------------------------+
| 特性                              | 说明                                                      |
+===================================+===========================================================+
| **GPU 零空闲**                    | Rollout 等待工具响应时，Trainer 继续训练                  |
+-----------------------------------+-----------------------------------------------------------+
| **Off-policy 支持**               | ``off_policy_step`` 允许使用略过期的数据，最大化吞吐      |
+-----------------------------------+-----------------------------------------------------------+
| **独立扩缩**                      | ``actor_gpus`` 和 ``rollout_gpus`` 可独立配置             |
+-----------------------------------+-----------------------------------------------------------+
| **故障隔离**                      | 单组件失败不会立即崩溃全部，通过 TaskCoordinator 优雅传播 |
+-----------------------------------+-----------------------------------------------------------+

关键配置
~~~~~~~~

.. code:: yaml

   trainer:
     actor_gpus: 4          # 训练用 GPU 数
     rollout_gpus: 4        # 推理用 GPU 数
     async_factor: 2        # 异步缓冲倍数
     off_policy_step: 2     # Off-policy 容忍步数
