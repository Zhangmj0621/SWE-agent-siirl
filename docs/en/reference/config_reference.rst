Overview
--------

All configuration in siirl-agentic is represented by the ``SiiRLArguments`` dataclass.
See the :doc:`Configuration System <../user_guide/configuration_system>` guide for usage patterns.

Top-Level Structure
-------------------

.. code:: yaml

   data:  # DataArguments — Dataset paths, batch sizes, tokenization
   actor_ref:  # ActorRefArguments — Actor, Ref, Algorithm, Checkpoint config
   rollout:  # RolloutArguments — Inference engine, sampling, multi-turn
   critic:  # CriticArguments — Critic model (PPO only)
   trainer:  # TrainingArguments — Training loop and resources
   custom_reward_function:  # CustomRewardArguments — Custom reward config
