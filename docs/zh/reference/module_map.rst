模块地图
========

   **适合谁：** 需要浏览 siirl-agentic 源码的开发者。

   **你将获得：** 顶层目录到其职责和关键文件的快速参考映射。

顶层结构
--------

::

   siirl-agentic/
   ├── siirl/                    # 主包
   │   ├── async_train.py        # 入口点：MainRunner Ray Actor
   │   ├── algorithm/            # RL 算法实现
   │   ├── data_coordinator/     # 异步数据缓冲与加载
   │   ├── engine/               # GPU 计算引擎
   │   ├── environment/          # 工具环境与基类
   │   ├── execution/            # Rollout 编排
   │   ├── models/               # 模型加载与权重管理
   │   ├── params/               # 配置数据类
   │   ├── utils/                # 共享工具函数
   │   └── worker/               # Ray Actor 工作进程
   ├── examples/                 # 训练脚本与配置
   ├── scripts/                  # 工具脚本
   ├── tests/                    # 测试套件
   └── docs/                     # 文档（本站）

模块详情
--------

``siirl/async_train.py``
~~~~~~~~~~~~~~~~~~~~~~~~

主入口点。将 ``MainRunner`` 实现为一个 8 阶段生命周期的 Ray Actor：

解析配置 → 分配资源 → 初始化 DataCoordinator → 初始化组件 → 异步训练循环 → 等待 → 检查状态 → 清理

``siirl/algorithm/``
~~~~~~~~~~~~~~~~~~~~

.. list-table::
   :header-rows: 1

   * - 文件
     - 说明
   * - ``advantage.py``
     - GAE 和 GRPO 组相对优势估计
   * - ``loss.py``
     - PPO 裁剪 loss、GRPO loss、熵奖励
   * - ``kl_penalty.py``
     - Actor 与 Reference 之间的 KL 散度计算

``siirl/data_coordinator/``
~~~~~~~~~~~~~~~~~~~~~~~~~~~

+---------------------+-------------------------------------------------------------------+
| 文件                | 说明                                                              |
+=====================+===================================================================+
| ``data_buffer.py``  | ``DataBuffer`` Ray Actor — rollout 与训练之间的异步样本缓冲       |
+---------------------+-------------------------------------------------------------------+
| ``protocol.py``     | 组件间数据交换协议                                                |
+---------------------+-------------------------------------------------------------------+
| ``sample.py``       | 样本打包、填充与张量构建                                          |
+---------------------+-------------------------------------------------------------------+
| ``dataloader/``     | 数据集加载与批处理逻辑                                            |
+---------------------+-------------------------------------------------------------------+

``siirl/engine/``
~~~~~~~~~~~~~~~~~

+--------------------------------+-------------------------------------------------------------+
| 目录                           | 说明                                                        |
+================================+=============================================================+
| ``actor/``                     | Actor 模型引擎（前向/反向，Megatron 集成）                  |
+--------------------------------+-------------------------------------------------------------+
| ``param_sync/``                | Actor 与 rollout 引擎之间的参数同步                         |
+--------------------------------+-------------------------------------------------------------+
| ``rollout/``                   | 基于 SGLang 的 rollout 推理引擎                             |
+--------------------------------+-------------------------------------------------------------+

``siirl/environment/``
~~~~~~~~~~~~~~~~~~~~~~

.. list-table::
   :header-rows: 1

   * - 文件
     - 说明
   * - ``base.py``
     - ``BasEnvironment`` 抽象基类，``EnvResponse`` Pydantic 模型
   * - ``tool_env/base_tool_env.py``
     - ``ToolEnv`` — OpenAI 函数调用工具 schema
   * - ``tool_env/aio_search_env.py``
     - ``AIOSearchEnv`` — 使用 AIO HTTP API 的具体工具环境

``siirl/execution/rollout/``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

+--------------------------------------+------------------------------------------------------------------------------------+
| 文件/目录                            | 说明                                                                               |
+======================================+====================================================================================+
| ``agentflow/base.py``                | ``AgentFlow`` 协议（``preprocess → generate → reward``）、``Sample``、``Model``    |
+--------------------------------------+------------------------------------------------------------------------------------+
| ``agentflow/__init__.py``            | ``load_agentflow()`` — 通过 YAML 配置的动态函数注入                                |
+--------------------------------------+------------------------------------------------------------------------------------+
| ``agent_flow/naive_flow.py``         | ``NaiveFlow`` — 多轮 rollout 状态机                                                |
+--------------------------------------+------------------------------------------------------------------------------------+
| ``agent_executor/``                  | Agent 执行编排器                                                                   |
+--------------------------------------+------------------------------------------------------------------------------------+

``siirl/utils/``
~~~~~~~~~~~~~~~~

+--------------------------------------+------------------------------------------------------------------+
| 文件/目录                            | 说明                                                             |
+======================================+==================================================================+
| ``task_coordinator.py``              | ``TaskCoordinator`` Ray Actor — 分布式生命周期管理               |
+--------------------------------------+------------------------------------------------------------------+
| ``checkpoint/``                      | 检查点保存/加载逻辑                                              |
+--------------------------------------+------------------------------------------------------------------+
| ``metrics/``                         | 训练指标收集与上报                                               |
+--------------------------------------+------------------------------------------------------------------+
| ``reward_score/``                    | 奖励评分函数（自定义奖励实现）                                   |
+--------------------------------------+------------------------------------------------------------------+

外部依赖
--------

+-----------------------------+---------------------------+-------------------------------------------------------+
| 组件                        | 包                        | 作用                                                  |
+=============================+===========================+=======================================================+
| 分布式编排                  | ``ray``                   | Actor 模型、资源管理                                  |
+-----------------------------+---------------------------+-------------------------------------------------------+
| 推理引擎                    | ``sglang``                | rollout 的高吞吐量 LLM 推理                           |
+-----------------------------+---------------------------+-------------------------------------------------------+
| 模型框架                    | ``transformers``          | 模型加载、分词                                        |
+-----------------------------+---------------------------+-------------------------------------------------------+
| GPU 训练                    | ``torch`` + Megatron-Core | 带张量/流水线并行的分布式训练                         |
+-----------------------------+---------------------------+-------------------------------------------------------+
| 工具调度                    | ``AIO``\ （同级项目）     | 弹性工具实例管理                                      |
+-----------------------------+---------------------------+-------------------------------------------------------+
