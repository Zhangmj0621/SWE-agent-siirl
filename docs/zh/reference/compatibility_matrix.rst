硬件要求
--------

最低配置（开发/测试）
~~~~~~~~~~~~~~~~~~~~~

- 1× NVIDIA GPU（A100 40GB 或同等配置）
- 64 GB 系统内存
- 100 GB 磁盘空间

推荐配置（生产训练）
~~~~~~~~~~~~~~~~~~~~

- 8× NVIDIA A100 80GB 或 H100
- 每节点 512 GB 系统内存
- 高速互联网络（NVLink / InfiniBand）
- 共享文件系统（NFS 或并行文件系统）

多节点
~~~~~~

- 所有节点必须有相同的 GPU 配置
- Ray 集群必须预先初始化或自动启动
- 节点间网络延迟 < 1ms（同一数据中心）
